# PLAN — Margin Lens

## 1. Аудиторія

- Хто: продавці Etsy (хендмейд, vintage, digital), малі Shopify-магазини, FBA/MFN-продавці Amazon.
- Біль: «продав товар за $30 — отримав $18–20, не розумію куди пішло» — fee stacking робить реальну маржу непрозорою; вибір каналу продажу робиться наосліп.
- Сегменти: solo-продавці (основний), малі майстерні 2–5 людей, resellers.
- Географія: глобально; VAT/PDV актуальний для ЄС/України, sales tax для US.

## 2. MVP scope (поточний реліз)

Включено:
- Калькулятор одного замовлення: Etsy / Shopify / Amazon, всі збори з реальними тарифами.
- Etsy: listing $0.20, transaction 6.5%, payment 3%+$0.25, offsite ads 15% опційно.
- Shopify: 2.9%+$0.30, місячна підписка розмазана по замовленнях.
- Amazon: referral по категоріях, per-item $0.99 опційно.
- VAT/PDV % налаштовуваний.
- Результати: net profit, margin %, breakeven-ціна (аналітичний розв'язок), слайдер «підняти ціну на X%».
- Batch CSV-вставка + таблиця результатів.
- Side-by-side порівняння трьох каналів.
- Сценарії в localStorage (зберегти/завантажити/видалити).
- pytest на чисті функції (`core/fees.py`).

Не включено (свідомо, для MVP):
- Облік advertising (Etsy Ads), FX-конвертація, регуляторний збір Etsy.
- FBA-збори (розрахунок за габаритами).
- Акаунти/хмара — все локально.

## 3. Архітектура

- **Фронт**: один `index.html` (vanilla JS, без залежностей, без збірки). Хостинг GitHub Pages — $0.
- **Логіка розрахунку**: чисті функції; Python-модуль `core/fees.py` — джерело правди для тестів, JS-дзеркало в `index.html` для офлайну. При зміні тарифів оновлювати обидва (поки свідомо; далі — генерувати JS-константи з Python).
- **Дані**: localStorage (`ml_scenarios`), JSON-структура сценарію: `{name, ts, inp, result}`.
- **Breakeven**: аналітичний — `P_total = (cost + shipping + fixed) / (1 - pct_total)`, `P = P_total - shipping_charged`; якщо `pct_total >= 1` — breakeven не існує (null).

## 4. Roadmap

- **v0.1 (MVP, зараз)**: калькулятор, batch CSV, порівняння каналів, сценарії, тести.
- **v0.2**: Etsy Ads + регуляторний збір; FX-курси; export CSV результатів; URL-share сценарію (params у hash).
- **v0.3**: FBA-калькулятор за габаритами/вагою; імпорт замовлень з Etsy/Shopify CSV exports.
- **v1.0**: Pro-функції, PWA-обгортка, i18n (UA/EN), сторінка-лендінг.

## 5. Монетизація

Freemium:
- **Free**: калькулятор однієї позиції, порівняння каналів, 5 збережених сценаріїв.
- **Pro (~$5–7/міс або $39 разово)**: batch без ліміту CSV (сотні позицій), збереження необмежених сценаріїв, історія цін, export, приоритетна підтримка оновлення тарифів.
- Канали продажу: Etsy-спільноти, r/EtsySellers, YouTube «скільки ви реально заробляєте».

## 6. Ризики

| Ризик | Імовірність | Мітигація |
|---|---|---|
| Платформи змінюють тарифи → застарілі розрахунки | Висока | Константи в одному місці; дата «тарифи станом на…» в UI; швидкий патч |
| Розбіжність JS-дзеркала і Python-модуля | Середня | Тести на однакових кейсах; надалі — кодогенерація JS з Python |
| Низька готовність платити у free-сегменті | Середня | Дешевий разовий Pro-тариф; $0 інфраструктура |
| Точність VAT (rise/marketplace collector rules) | Середня | Дисклеймер + налаштовуваний %, не претендуємо на податкову консультацію |
| Конкуренція (Sale Samurai, eRank) | Середня | Фокус на margin/breakeven, а не на keyword-дослідженні |

## 7. Метрики успіху

- Активність: MAU, розрахунків/користувача, повторні візити.
- Конверсія free→Pro ≥ 3%.
- NPS / відгуки в Etsy-спільнотах.

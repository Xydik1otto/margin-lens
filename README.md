# Margin Lens — калькулятор зборів та маржі для Etsy/Shopify/Amazon

## Проблема

Продавці на маркетплейсах не бачать свою **реальну** маржу. Дослідження перед MVP:

- **76 pay-сигналів** у e-commerce — збори стягуються звідусіль: listing fee, transaction fee, payment processing, offsite ads, підписка, referral по категоріях. **Fee stacking** (накопичення зборів) — головний біль продавців.
- LinkedIn-аналіз: типовий продавець отримує **$18–20 з товару за $30** після всіх зборів і **не знає**, скільки саме «з'їдає» кожен канал. Без розрахунку неможливо зрозуміти, який канал вигідніший і де точка беззбитковості.

## Що це

SPA **без бекенду**: vanilla JS + localStorage, один `index.html` — розгорнуто на GitHub Pages за $0.

- Калькулятор: ціна, собівартість, доставка (платите/платить покупець), платформа → всі збори по черзі (fee stacking наочно)
- Etsy: listing $0.20, transaction 6.5%, payment 3% + $0.25, offsite ads 15% (опційно)
- Shopify: 2.9% + $0.30, місячна підписка розмазана на замовлення
- Amazon: referral по категоріях (8–20%), $0.99/товар для індивідуального плану
- VAT/PDV % налаштовуваний
- Результат: **net profit, margin %, breakeven-ціна**, слайдер «а якщо підняти ціну на X%»
- Batch-режим: вставка CSV зі списком товарів
- Side-by-side порівняння каналів
- Збережені сценарії в localStorage

Чиста логіка розрахунку — у Python (`core/fees.py`), покрита тестами; `index.html` дублює ті самі тарифи в JS для офлайн-роботи.

## Швидкий старт

```bash
# SPA: просто відкрити файл
start index.html          # Windows (або відкрити в браузері)

# Тести розрахунку зборів
python -m pip install pytest
python -m pytest tests/ -v
```

Для GitHub Pages: запушити репозиторій, Pages → гілка `main` → корінь. Файл один, збірка не потрібна.

## Структура

```
margin-lens/
├── index.html        # SPA (калькулятор + batch + порівняння + сценарії)
├── core/fees.py      # чисті функції розрахунку зборів (джерело правди)
└── tests/test_fees.py
```

## Дисклеймер

Тарифи зафіксовані станом на 2025 рік і змінюються платформами. Дані про збори — у відкритих тарифних сторінках Etsy/Shopify/Amazon; оновлюйте константи в `core/fees.py` та `index.html` при зміні.
